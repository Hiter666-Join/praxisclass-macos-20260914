# 真需实创 · 20260914 内测部署包

本包冻结 2026-09-14 当前开发版本，包含已确认的 harness 与演示入口收拢调整。Windows 与 macOS 使用同一份源码；旧内测包和远程部署不随本次交付更新。

## 开始使用

1. 完整解压到固定目录。Windows 建议用较短路径，例如 `C:\PraxisClass-20260914`；不要在 ZIP 预览窗口中运行，也不要覆盖旧版目录。建议准备至少 12 GB 可用空间。
2. 安装并启动 Docker Desktop，等待引擎就绪。它用于运行本包独立的 PostgreSQL 16。首次可能需要联网拉取镜像；本包不包含 Docker Desktop 或数据库镜像。
3. 安装 Chrome，供 Pro 的浏览器互动检查使用。缺少 Chrome 时应用仍可浏览，但互动检查会显示“未验证”；也可在 `PraxisClass/.env.local` 配置 `PRAXIS_BROWSER_EXECUTABLE` 指向已有 Chromium。
4. Windows x64 双击 `start-windows.cmd`；macOS（Apple Silicon / Intel）双击 `start-macos.command`。若 macOS 未保留执行权限，在本目录终端运行 `chmod +x *.command .tools/bin/pnpm`，然后运行 `./start-macos.command`。
5. 首次启动会解压离线缓存、安装锁定依赖、构建内部课件组件、生成训练资源并启动数据库。结束前保持终端打开；随后打开 **http://127.0.0.1:3210/portal**。
6. 在教师或学生侧分别填写该侧模型、API Key 和服务地址。初始无预选模型或私有凭据；不要求修改固定模型路由来使用页面中的 Pro。Dify、远程解析、图像和语音服务按需要配置。

运行时为内置 Node.js 24.14.0、pnpm 10.28.0，无需另装 Node。应用依赖来自随包离线缓存；AI 服务、首次数据库镜像下载及部分外部素材仍需要网络。代码练习使用的 Pyodide 也需要浏览器下载对应资源。

## 数据、停止和再次启动

- 应用仅监听本机 `127.0.0.1:3210`。Pro 与共享存储默认启用；数据库仅监听本机 `127.0.0.1:55414`。
- 首次运行生成 `PraxisClass/.env.local` 和 `.tools/local-deployment.json`，其中的数据库密码与演示持久化令牌只属于这份解压目录。不会覆盖已存在的配置。
- 平台业务数据写入 `PraxisClass/data/`；共享课堂、材料和 Agent 会话使用本包独立 Docker 卷。浏览器端设置和部分课堂缓存仍依赖相同浏览器与访问地址。
- 停止应用：在运行终端按 `Ctrl+C`。再双击 `stop-windows.cmd` / `stop-macos.command` 停止本包数据库，数据保留。下次双击启动文件即可继续使用。
- 不要删除 Docker 卷、`.tools/local-deployment.json` 或 `.env.local` 来解决一般启动错误。退出应用前先保存课程；需要备份时同时保存课堂导出包、配置、平台数据和数据库。
- 旧版数据不会自动导入。需要迁移课程时，先在旧版导出课堂包，再在新版正常导入。请保留原目录直到验证迁移成功。

## 常见情况

| 情况 | 处理 |
| --- | --- |
| Docker 未启动 | 打开 Docker Desktop，等待引擎就绪，再启动本包。不会悄悄改用缺少 Pro 的模式。 |
| 数据库端口占用 | 首次运行前设置 `PRAXIS_PG_PORT` 为其他空闲端口。若已初始化，需同步修改 `.tools/local-deployment.json` 的 `port` 与 `.env.local` 中数据库 URL 的端口。 |
| 应用端口占用 | 设置 `PRAXIS_DEMO_PORT` 后运行启动器，例如 Windows `set PRAXIS_DEMO_PORT=3211`，macOS `PRAXIS_DEMO_PORT=3211 ./start-macos.command`。更换端口会形成新的浏览器存储空间。 |
| 缺少模型配置 | 进入当前端设置填写自己的模型服务信息；本包不携带开发者密钥。 |
| 浏览器检查不可用 | 安装 Chrome 或指定 `PRAXIS_BROWSER_EXECUTABLE`；“未验证”不能当作检查通过。 |
| Windows 路径过长 | 重新解压到较短路径，保留完整目录，不单独搬运 `node_modules`。 |
| macOS 下载文件被系统拦截 | 使用系统提供的“打开”或“隐私与安全性”确认选项，仅对可信来源的本包操作；无需关闭系统整体保护。 |
| 希望接入已有 PostgreSQL | 在 `.env.local` 填写可用 `DATABASE_URL` 和匹配的持久化令牌；启动器会验证连接。它不会删除或重置指定数据库。 |

`start-demo.mjs --prepare-only` 只准备依赖和内部组件，不启动数据库或应用；`--check` 只检查包入口文件；`--stop` 停止本包管理的数据库。
