响应还需要怎样理解

请求体合格不等于产品问题已经有充分依据。HTTP 200 时还要读取业务 status、answer 与 sources；角色条件未知、读过资料仍不足、资料读取失败是不同情形。

HTTP 200 + need_clarification：补充影响回答的条件
HTTP 200 + insufficient_evidence：已读取指定资料，但无法确认
HTTP 400 + invalid_request：请求格式或字段不符合契约
HTTP 503 + resource_unavailable：资料或处理服务暂不可用

依据：CONTRACT-MAIN 第1—5节；TECH-HTTP。路径、字段与业务状态属于本题契约。@RequestBody 不自动完成任意业务校验或用户鉴权。
