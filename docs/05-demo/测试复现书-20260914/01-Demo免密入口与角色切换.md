# Demo 免密入口与角色切换

验证日期：2026-09-14。当前状态：已在新的 Chrome 会话实际通过。准备条件见[入口说明](00-复现入口与准备.md)。

## 为什么改为免密

企业老师提出：“都尽量免密登录，因为是 demo。”本版将教师 PIN、整站访问码和相应输入弹窗取消；教师与学生选择角色即可进入。登录页备注为“Demo 演示版：教师与学生均可免密进入，无需注册。”变更已登记到工作区`docs/04-history/OpenMAIC二次开发-变更笔记.md`的2026-09-14免密条目；本节同步保留需求来源，便于本复现目录独立交付。

## 页面步骤与预期

| 步骤 | 操作 | 必须观察到的结果 |
|---|---|---|
| 1 | 新开 Chrome 会话，进入 `/portal` | 显示教师、学生入口和 Demo 免密说明；没有 PIN／密码输入框 |
| 2 | 点击教师入口 | 到达教师工作台；未要求输入口令 |
| 3 | 使用页面角色切换回入口，选择学生 | 到达学生学习空间；未要求输入口令 |
| 4 | 刷新当前学生页 | 保持页面可进入，不出现访问码弹窗 |
| 5 | 分别打开教师、学生设置 | 两端各自选择服务；进入角色本身不依赖模型已配置 |

第 5 步不要求展示或抄录密钥。模型未配置时，课堂资料和确定性选择题仍可操作；需要 AI 的步骤会要求配置当前端服务。

## 兼容与边界

旧 `TEACHER_PIN`、`ACCESS_CODE` 环境值不会重新开启拦截。旧 `/portal?key=...` 链接会去掉 key 参数并进入教师页。对应行为有定向接口测试；不会在复现书展示旧口令。

免密不等于把所有记录混成一份。任务所有者、学习者、演练／学习记录及当前端服务设置仍独立。学生显式角色不能调用教师编辑业务；异身份读取成果等边界见[共享成果复现](03-共享成果与恢复.md)。
