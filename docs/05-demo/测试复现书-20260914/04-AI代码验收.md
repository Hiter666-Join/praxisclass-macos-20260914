## 修订：旧运行不能证明新代码

1. 从任务返回实训，点“修改后再提交”。把D2预期改为1，在理由中说明依据首次位置修正。
2. 可用下面这份本轮修订代码复现；它是一种参考修订，不要求学生逐字照抄，也不用于证明独立完成：

```python
def solution(nums, target):
    left, right = 0, len(nums) - 1
    answer = -1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            answer = mid
            right = mid - 1
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return answer
```

3. 尚未重跑时，页面应提示旧运行不能证明当前代码，“保存”不可用。旧的8/12记录仍保留，不能显示为新代码已经通过。[拦截截图](证据/training-p2-stale-run-blocked-20260914.png)
4. 重新试跑上述诊断，本轮5/5符合，D2实际为整数1。运行固定验收，本轮12/12符合。再次实际运行相同代码仍应产生不同运行编号；在正式保存前，不新增成果。
5. 填写修改原因和受辅导情况。选择“本次验证范围内接收”，说明当前代码的最新固定运行12例符合，并保留未验证范围。点“保存验收记录”。预期生成新成果编号，关联第一稿，旧稿和旧评价仍可读。[修订保存截图](证据/training-p2-revision-saved-20260914.png)
